# Clean grids

`tokens.css`, `tokens-dark.css` and `grids.css` here, and `public/theme.js`, are
copies of the Clean grids design template (`Designs/clean-grids`, commit
`9fbce14`). They are unchanged. To update, copy the four files over again.

The app uses the indigo palette (`data-accent="indigo"` on `<html>`). Its own
layout lives in `src/style.css` and uses the tokens only.
